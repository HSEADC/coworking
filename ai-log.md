#### #[2] · [21.10.26] · [Полина]

- **Задача:** сделать анимацию стопки из трёх карточек в блоке «О нас»: передняя карточка уходит назад, а остальные по очереди выдвигаются вперёд, и так по кругу. Сначала думала, что для этого нужен JavaScript, и спросила у ИИ, как лучше это реализовать.
- **Запрос:** «Как сделать анимацию, чтобы карточки в стопке по очереди менялись местами: передняя уходит назад, остальные выдвигаются вперёд? Лучше делать это через JS?»
- **Что выдал ИИ:** объяснил, что JS не нужен и всё можно сделать на CSS через `@keyframes`. Карточки двигаются с помощью `transform` (`translate` для сдвига и `scale` для уменьшения), а порядок слоёв меняется через `z-index`. Всем карточкам назначается одна анимация с разной задержкой, поэтому они проходят цикл со сдвигом друг относительно друга.
- **Что изменила и почему:** подобрала значения `translate` и `scale` (7.9% / −38.5% / 0.84 для дальней карточки и 4% / −21.4% / 0.92 для средней), чтобы положения карточек совпадали с макетом. Сделала так, чтобы `z-index` менялся только в моменты, когда карточка стоит на месте или уже ушла назад (на 23% и 33%). Иначе во время движения карточка проезжала поверх остальных.
- **Итог и проверка:** анимация `card-move__about` в `src/stylesheets/animation.css`, коммит [не коммитила]. Проверила в [Chrome]: карточки меняются по кругу, слои не перекрываются неправильно, в момент смены переднего плана нет рывка.
